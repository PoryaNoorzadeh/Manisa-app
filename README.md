# Manisa App

Local-first smart home platform for Manisa Matter devices.

## Platform principles

- Local-first operation
- Manisa-owned API and product model
- Matter as the primary device interoperability layer
- Replaceable open-source engines behind adapters
- Cloud is optional and never in the critical path for local control

## Initial stack

- Manisa Core: Go modular monolith
- Mobile App: Flutter
- Local DB: SQLite
- Matter: Open Home Foundation Matter Server / matter.js
- Automation & integrations: Home Assistant
- Thread: OpenThread Border Router (OTBR)
