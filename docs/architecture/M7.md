# M7.1 — Product experience foundation

Version: 0.23.0+28. Scope: replace the prototype-style information architecture with a product-level Persian experience while preserving the validated Matter, readback, recovery and schedule contracts.

## UX boundary

- Home is the daily-control surface: home health, favorites, spaces and devices.
- Work is separated into manual scenes and phone-owned schedules.
- Low-frequency home, room, connectivity and support information lives in Settings.
- Device-specific actions remain contextual to the device.
- Unavailable, stale, pending, on and off remain distinct states.

## Design system

The «خانهٔ آرام» language introduces Manisa Teal, warm neutral surfaces, ink-first typography, 22dp bordered cards, 16dp controls, Persian-first line height and minimum 48dp targets. Color is never the only state signal.

## Preserved contracts

- Direct Matter over Wi-Fi commissioning and real readback.
- Endpoint identity, rooms, favorites, sensor and energy information.
- Automatic connection recovery without command replay.
- Scene execution with per-output confirmation, stop and explicit retry.
- Phone-owned schedules with at-most-once slot claims and a ten-minute catch-up window.

## Validation target

Flutter format/analyze/tests, Go race tests/build, generic Android, official Matter controller and integrated ARM64 release APK. Hardware acceptance remains separate for real transport recovery, RGB/readback, sensor values and scheduled multi-output execution.
