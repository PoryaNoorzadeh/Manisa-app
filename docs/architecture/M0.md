# M0 — Foundation

## Goal

Establish a production-shaped but minimal local-first foundation that can evolve into the Manisa Hub software stack.

## Deliverables

- Go modular-monolith service
- Versioned `/api/v1` boundary
- Liveness and readiness endpoints
- SQLite with WAL and foreign keys
- Initial Home / Room / Device persistence schema
- Container image and local Compose environment
- CI formatting, vet, tests, race detector, and build
- Architecture Decision Records

## Next slice

Add domain repositories and CRUD API for Home, Room, and Device, followed by a MatterController interface and a matterjs-server adapter.
